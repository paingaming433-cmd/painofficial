TamilPainGaming Website
========================
Files:
- index.html
- style.css
- script.js
- images/banner.jpg
- images/logo.jpg
- audio/mass-bgm.wav

How to use:
1. Extract the ZIP.
2. Open the TamilPainGaming folder in VS Code.
3. Open index.html in Chrome (Live Server recommended).
4. Click ENTER THE PAIN ZONE to start the original Tamil-style mass BGM.
5. Edit links/text in index.html if needed.

Note:
The included BGM is an original generated instrumental loop, not a copyrighted Tamil movie/song track.

Mouse click sound: built into script.js with Web Audio API; no MP3 file is required.

Cyber Click Sound: audio/cyber-click.wav is used for mouse clicks and button clicks.
